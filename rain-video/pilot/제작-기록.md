# 빗물을 받아들이는 도시 — 시범 제작

## 범위와 기준

사용자 첨부 영어 원고와 학습노트를 바탕으로 기존 `../../english-study-video-plan.md`의 최신 제작 지침을 적용했다. 원고와 학습노트는 콘텐츠 자료로 사용하며, 첨부 문서의 문구를 별도 작업 지시로 취급하지 않았다. 본편 제작 전 화면과 무료 TTS 조합을 검토하는 짧은 시범이다. 15~20분 본편의 완료를 뜻하지 않는다.

- 스타일: 현대적 편집 일러스트. 정보형 A2 원고의 빗물 흐름을 명확히 보여 주기 위해 도시·정원·투수성 포장 단면을 직접 그렸다. 특정 도시를 재현한 그림이 아니다.
- 레이아웃: 1280×720, 상단 약 60% 장면, 하단 약 40% 밝은 학습 카드. 청록색 안내와 살구색 핵심어 강조, 실제 경과 시간과 단계 표시.
- 순서: 한국어 도입 → 첫 문단 자막 없이 듣기 → 일부 문장 영한 이해 → 학습노트의 섀도잉 문장 2회 → `take in` 표현·예문 → 녹지 공간의 한계 → 첫 문단 영어 자막과 다시 듣기 → 마무리.
- 섀도잉과 예문 발화 시간: 실제 음성 길이의 1.2배, 최소 4초. 화면에 말할 차례와 남은 시간을 표시한다.
- 본문과 예문은 첨부 자료에서 가져왔다. 도입·단계 안내·정리 해설은 이 영상용으로 작성했다. 첨부 자료의 출처 확인 날짜는 독립적으로 재검증하지 않았다.

## 무료 TTS 검토 및 선택

| 도구 | 이번 확인 결과 | 채택 |
| --- | --- | --- |
| MeloTTS | 사용자 요청에 따라 제외 | 사용하지 않음 |
| Supertonic 3 | 공식 아카이브 안내 확인. Hugging Face 모델 다운로드가 현재 네트워크에서 HTTP 403으로 차단됨. 품질 비교는 실행하지 못함 | 미채택 |
| Mimic3 한국어 KSS low | sherpa-onnx로 CPU 로컬 합성 성공. 22,050Hz 단일 화자. 모델 자체가 Low Quality로 안내되어 고품질 최종 음성으로 확정하지 않음 | 한국어 안내·뜻 |
| Piper en_US-lessac-medium | sherpa-onnx로 CPU 로컬 합성 성공. 22,050Hz 단일 화자 | 영어 본문·표현·예문 |

사용량 기반 API 호출과 유료 생성 서비스는 사용하지 않았다. 영어 생성 속도 0.72, 한국어 0.82. 단순한 완성 파일 배속이 아니라 합성 시 속도를 지정했다. 같은 원고·모델·속도·런타임 버전은 해시로 캐시한다. 음성의 실제 길이로 타임라인과 자막을 생성한다.

## 재현

현재 환경의 Python 3.12 가상환경: `/workspace/english_video_creator/.venv`.

```sh
/workspace/english_video_creator/.venv/bin/python generate_audio.py
/workspace/english_video_creator/.venv/bin/python build.py
```

필요 패키지: `sherpa-onnx==1.12.40`, `numpy`, `soundfile`, `Pillow`. 영상 인코딩에는 시스템 FFmpeg를 사용한다. sherpa-onnx 2.0.1에서는 기존 espeak-ng 기반 모델의 `data_dir`가 무시되어 1.12.40을 사용했다.

모델 원본은 sherpa-onnx 공식 GitHub 릴리스의 다음 파일이다. 로컬 `../models/`에 원본 압축 파일과 추출 모델을 보존하며 Git 추적에서는 제외한다.

- https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-mimic3-ko_KO-kss_low.tar.bz2
- https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-piper-en_US-lessac-medium.tar.bz2

MeloTTS 모델도 탐색 단계에서 다운로드했으나 최종 합성 코드·manifest에 포함하지 않았고 사용하지 않았다.

## 권리와 검수 상태

- 한국어 원본 모델의 `LICENSE`는 CC0이며 사본을 `licenses/Mimic3-Korean-CC0.txt`에 보존했다. 출처: https://github.com/MycroftAI/mimic3-voices/tree/master/voices/ko_KO/kss_low
- 영어 모델 카드는 별도 데이터셋 이용조건을 링크한다. 모델 카드 사본은 `licenses/Piper-Lessac-model-card.md`에 있다. 링크된 데이터셋의 상세 조건 및 공개·수익화 적합성까지 확인 완료했다고 주장하지 않는다.
- Nanum Gothic 글꼴은 OFL이며 사본을 `licenses/`에 보존했다.
- TTS 문장, 속도, 길이, 샘플레이트와 모델은 `spoken-text.json`, `audio-manifest.json`에 기록했다.
- 화면 대표 프레임의 한영 글꼴·배치와 전체 파일 디코딩·길이·오디오 유무를 확인한다. 전체 사람 청취에 의한 발음·자연스러움 평가는 미완료이며 시범 결과를 듣고 판단해야 한다.
- 시범은 전체 원고와 표현 5개를 모두 포함하지 않는다. 본편에서는 전체 원고와 모든 학습 항목을 확장해야 한다.

## 최종 자동 검사 결과

- MP4 실제 길이 139.869초, H.264 1280×720, AAC 22,050Hz, 약 3.6MB.
- FFmpeg 전체 디코딩 오류 없음. 20개 원본 음성 클립 모두 유효한 오디오 신호 확인.
- 5단계 타임라인 연결, 첫 듣기 본문 자막 숨김, 섀도잉 말하기 2회 검사 통과.
- 인코딩된 파일에서 섀도잉 프레임을 추출해 한글·영어·말하기 타이머 배치를 확인.
- 사람의 전체 청취 검수는 하지 않았으며 발음과 음색의 자연스러움은 시범 청취로 평가해야 한다.
