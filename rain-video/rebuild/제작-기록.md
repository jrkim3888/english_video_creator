# 빗물을 받아들이는 도시 — 재제작 기록

## 제작 순서와 결과

수정된 제작 플랜에 따라 대표 이미지와 장면 이미지 7개를 먼저 생성하고, 그 이미지에 원고 전체 35문장과 학습 대본을 연결했다. 이후 문장별 음성을 생성·재사용하고 영상과 썸네일을 조립했다. 앞선 2분 20초 도식 시범을 덮어쓰지 않고 별도 폴더에 보존했다.

- 화풍: 현대적 편집 일러스트, 질감 있는 과슈·스토리북 표현.
- 이미지: 빗물 정원, 도시 유출수, 숲, 투수성 포장, 녹화 지붕, 녹지 편익, 관리와 배수.
- 영상: 1280×720, 12fps, 상단 약 60% 일러스트와 완만한 이동, 하단 고정 학습 카드.
- 본문: 첨부된 영어 원고 306단어·35문장 전체.
- 학습: 자막 없는 첫 듣기, 문장별 영한 이해와 문단 해설, 전체 문장 1회 섀도잉과 학습노트 핵심 5문장 추가 1회, 표현 5개·예문·회상 발화, 영어 자막과 다시 듣기.
- 본편 시간표: 실제 오디오로 계산한 1159.83초. chapters.md 참조.
- 썸네일: 같은 빗물 정원 일러스트와 확인된 L2 / A2 배지, 영어 제목·한국어 설명을 별도 레이어로 합성.

## 음성과 사용량

Google TTS는 이 환경에 인증이 없어 호출하지 않았다. 이 대화에서 허용된 무료 로컬 대안인 한국어 Mimic3 KSS low와 영어 Piper lessac medium을 사용했다. MeloTTS는 사용하지 않았다. Google 음성으로 생성한 영상이라고 설명하지 않는다.

- 런타임: sherpa-onnx 1.12.40 CPU. 영어 속도 0.72, 한국어 0.82.
- 원본 음성 샘플레이트: 22,050Hz.
- 이전 시범 파일 재사용: 12개.
- 이번 신규 고유 발화 생성: 96개.
- 유료 TTS API 호출: 0회.
- 영상의 영어·한국어 합성 파일은 같은 문장을 학습 단계마다 다시 생성하지 않고 재사용했다. 입력 텍스트·모델·속도·언어·런타임 버전의 해시를 ../audio-cache/에 저장한다. 다른 순서·영상 ID에 의존하지 않는 캐시다.
- 한국어 모델은 공식 모델명이 low이며 품질이 고급 음성과 동등하다고 확정하지 않는다.

## 이미지와 권리 기록

기본 이미지 생성 도구로 만든 가상 장면이며 실제 특정 도시의 사진이 아니다. 원본 생성 파일은 /workspace/generated_images/에 보존했고 영상용 이미지는 images/에 분리했다. 이미지 프롬프트와 화풍 선택 이유는 images/prompts.md와 images/style-selection.md에 보존했다. 유료 Runway 생성은 사용하지 않았다.

폰트 및 TTS 모델 조건은 ../pilot/licenses/의 사본과 이전 제작 기록을 참조한다. 한국어 원본 모델 LICENSE는 CC0이고, 영어 Piper 모델 카드는 별도 데이터셋 이용조건을 링크한다. 그 상세 조건과 공개·수익화 적합성까지 검증 완료한 것으로 취급하지 않는다.

## 재현

가상환경에 requirements-render.txt의 패키지와 FFmpeg가 필요하다. ../models/에 이전 시범에서 다운로드한 두 모델이 있어야 한다. 원고와 학습노트는 ../script.md, ../study-notes.md다.

```sh
python prepare_lesson.py
python generate_audio.py
python assemble_timeline.py
python render.py
python thumbnail.py
python verify.py
```

images/의 사전 생성 이미지도 보존해야 한다. API 인증이나 키를 저장소에 넣지 않는다.

## 검수 범위와 남은 항목

verification.json은 전체 디코딩과 음성 신호, 문장 수·표현 수·반복 횟수·단계 연결·길이 검사 결과를 기록한다. 화면 대표 프레임과 모바일 크기 썸네일의 글꼴·배치를 확인한다. 전체 영상의 사람 청취에 의한 발음·자연스러움 검수는 완료하지 않았다. 출처 페이지의 날짜와 사실관계도 이번 제작에서 독립적으로 다시 검증하지 않았으며, 첨부 학습노트의 기록을 유지한다.

## 최종 검사 결과

- 실제 MP4 길이: 1160.000초, 19분 20초.
- 전체 파일 디코딩 통과. 원고 35문장, 표현 5개, 이미지 7개, 단계별 전체 듣기 누락 없음.
- 음성 108개 모두 유효 신호 확인. 기존 파일 재사용 12개, 신규 고유 발화 96개, 유료 TTS 호출 0회.
- 인코딩 파일에서 섀도잉·숲 장면의 말하기 카운트다운·마지막 장면을 추출해 배치 확인. 썸네일은 384×216에서도 확인.
- 첫 인코딩에서 오디오 뒤에 남은 화면 구간을 발견해 음성 길이에 맞게 잘랐고, 재현 코드에도 출력 시간 제한을 추가했다.
- 사람의 전체 청취 검수와 독립 사실·상업적 이용조건 확인은 남아 있다.
